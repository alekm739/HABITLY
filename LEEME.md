# Habitly (web)

Seguidor de rutinas instalable como app (PWA). Todo se guarda en el teléfono, no necesita servidor.

## Publicarla gratis con GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `habitly`).
2. Sube estos archivos tal cual: `index.html`, `manifest.json`, `sw.js` y la carpeta `icons/`.
3. En el repo: Settings → Pages → Branch `main` / carpeta `/ (root)` → Save.
4. En un minuto queda en `https://TU-USUARIO.github.io/habitly/`.

También sirve Netlify Drop: arrastra la carpeta completa a https://app.netlify.com/drop

## Instalarla
- Android (Chrome): abre el link → menú ⋮ → **Instalar app**.
- iPhone (Safari): Compartir → **Agregar a inicio**.

## Respaldo
Tus datos viven en el navegador del teléfono. Usa la pestaña **Respaldo** para descargar un JSON de vez en cuando.
